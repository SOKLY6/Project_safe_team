# Web Portal - React приложение


### Production сборка

#### Вариант 1: Запуск через docker-compose (рекомендуется)

Этот способ не требует установки npm зависимостей на вашем компьютере. Все зависимости устанавливаются автоматически внутри Docker контейнеров.

1. Перейдите в корневую директорию проекта:
```bash
cd ..
```

2. Запустите все сервисы (бэкенд, веб-портал, телеграм-бот):
```bash
docker-compose up --build
```

При первом запуске или после изменений используйте флаг `--build` для пересборки образов.

3. Откройте браузер и перейдите по адресу:
```
http://localhost
```

**Важно:** 
- Убедитесь, что на вашем компьютере установлены Docker и Docker Compose
- Веб-портал будет доступен на порту 80
- Бэкенд API будет доступен на порту 8000
- Все зависимости (npm, Python) устанавливаются автоматически внутри контейнеров

#### Вариант 2: Запуск только веб-портала через Docker

1. Соберите приложение:
```bash
npm run build
```

2. Запустите через Docker:
```bash
docker build -t web-portal .
docker run -p 80:80 web-portal
```

## Структура проекта

- `src/` - исходный код React приложения
  - `pages/` - страницы приложения
  - `components/` - переиспользуемые компоненты
  - `contexts/` - React контексты (AuthContext)
  - `services/` - API сервисы
- `public/` - статические файлы
- `nginx.conf` - конфигурация nginx
- `Dockerfile` - Docker образ для production

## Маршруты

- `/login` - страница входа (начальная страница)
- `/dashboard` - главная панель
- `/scan-qr` - проверка QR-кодов
- `/visitors` - управление посетителями
- `/statistics` - статистика доступа
- `/staff` - управление охранниками (только для админов)
- `/api-panel` - панель управления API (только для админов)

## API

Все API запросы проксируются через nginx на бэкенд сервер (порт 8000).
